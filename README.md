## ✨ Features

* **🌠 Dynamic Scene Transitions:** Crossfades smoothly between high-resolution cosmic background images (Deep Space Nebula, Andromeda Spiral, and Astral Veil) with a subtle Ken Burns slow-zoom animation.
* **🎧 Immersive Soundscape:** Integrated ambient space audio track with custom play/pause controls, smooth volume sliders, and loop support.
* **✨ HTML5 Starfield Canvas:** A lightweight, custom-coded particle engine rendering drifting starlight over the background layers.
* **⌨️ Keyboard Shortcuts:** Navigate and control your experience effortlessly without breaking immersion.
* **💎 Glassmorphism UI:** Modern, clean glass UI controls that can be toggled on or off for a distraction-free full-screen display.
